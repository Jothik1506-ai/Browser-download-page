Security & Trust

An agent with hands
should have limits.

AIVA is built with the assumption that the pages it reads are untrusted and the actions it takes should be reversible by default.

  • Permission before payment or credentials

    The agent is instructed to never enter payment details or credentials, or take irreversible actions, without your explicit confirmation.

  • Bounded, cancellable runs

    Every agent run has a hard step cap and a visible Stop control — no silent, open-ended automation.

  • Page content treated as untrusted

    Text read from a site is never treated as an instruction to the agent — only as information about the page.

  • Open, inspectable core

    The browser core is open source, so the way it navigates and acts on your behalf can be audited, not just trusted.
