Why AIVA

Browsers got faster.
They never got smarter.

Every tab you open is still a task you finish yourself — click by click, form by form. AIVA is being built to turn intent into action, without handing over control of what happens on your machine.

Hours back, not tabs

Delegate the parts of browsing that don't need you — starting today with reading and summarizing pages, with clicking and form-filling actively in development.

Built with limits in mind

The agent is instructed to never enter payments or credentials without asking. A hard, enforced confirmation step before consequential actions is on the roadmap.

Still just a browser

Fast, familiar, Chromium-based. The agent is a layer you can lean on or ignore — it never gets in the way of ordinary browsing.

The core differentiator

It reads you, not just the page.

Other agentic browsers read the page they're on and act on it. AIVA also reads the person using it. The face scanner — built for fatigue detection — keeps a rolling 15-minute picture of your strain, screen time, and time since your last break, and feeds it straight into the same agent that's driving your browser.

Available now

The agent interrupts itself

Past step 5 of a long task, if you've been visibly worn out for a sustained stretch, the agent stops and asks — keep going, or pause for a break — instead of quietly burning through the rest of its step budget.

Available now

It answers differently, not just more

At high strain, responses get shorter and skip optional side-quests. It never diagnoses you, and mentions your state at most once per conversation — never repeatedly.

Available now

Camera-driven nudges, not fake timers

Posture is genuinely measured: AIVA learns your neutral sitting position over the first 20 seconds, then flags real drift — slouching, leaning in, a tilted head — after 45 seconds sustained. Eye-care reminders follow the real 20-20-20 rule based on actual detected screen time. Only water stays a plain timer — no webcam detects thirst.

Available now

It offers, never forces

Breathing, neck-exercise, and meditation break suggestions arrive as a card with a button. Your work is never touched, and nothing navigates without your click.

Security & trust

An agent with hands
should have limits.

Here's exactly what's enforced today, what's only an instruction to the model, and what's still on the roadmap.

  • ✓

    Page content is reference, not instructions Today

    The current page's visible text and URL are sent to the model only as context — never executed or treated as a command.

  • ✓

    Bounded, cancellable runs Today

    Every agent run has a hard 14-step cap and a visible Stop control — no silent, open-ended automation.

  • !

    Told not to touch payments or credentials Instruction, not enforced

    The system prompt tells the agent never to enter payment details or credentials. That's model guidance today — not yet a hard, code-enforced block.

  • ○

    Enforced approval & audit log Planned

    A UI confirmation step before consequential actions, and an audit log of everything the agent does, are planned but not built yet.

  • ✓

    Public source on GitHub Today

    The code is public and viewable today. A formal open-source license hasn't been published yet, so treat it as source-available for now.
